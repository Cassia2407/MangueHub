Desafios

Obstáculos que viraram aprendizado

Cada problema encontrado foi uma oportunidade de crescer.

PROBLEMA
Firmware não compilava
SOLUÇÃO

Uma string de depuração estava quebrada com uma quebra de linha "crua" no meio do código, o que travava a compilação. Foi identificada e corrigida com o escape \n.

Depuração de sintaxe em C/C++.
PROBLEMA
Planta só reagia a cada 30 segundos
SOLUÇÃO

A reação na matriz de LED estava presa dentro do mesmo bloco da leitura periódica. Separamos "decidir o estado" (a cada 30s) de "mostrar o estado" (a cada loop), com uma máquina de estados (enum + switch).

Uso de millis() sem travar o loop principal.
PROBLEMA
Calibração do sensor de umidade do solo
SOLUÇÃO

Os limites de leitura tinham sido definidos em bancada. Depois que a planta foi transferida para o pote acrílico definitivo, o sensor foi testado direto na terra real para ajustar os valores.

Calibração com dado real, não só teórico.
PROBLEMA
Prazo curto para hardware + firmware + site
SOLUÇÃO

Com apenas 30h distribuídas em 5 dias, priorizamos deixar o hardware e o firmware funcionais como entrega garantida, tratando a interface web em paralelo e aceitando fechá-la só no último dia.

Gestão de escopo sob prazo curto.
PROBLEMA
Arduino e site ainda não conversam entre si
SOLUÇÃO

A ponte de comunicação entre o firmware e a interface web (via ESP32/Wi-Fi) não coube no tempo do sprint. Ficou documentada como próximo passo no roadmap, com o site funcionando de forma independente por enquanto.

Roadmap realista além do sprint.
